Helm repository · gfs

This site hosts the Helm chart index for deploying gfs on Kubernetes. Published from groot-share-selfhosted.

Helm clients fetch index.yaml — a browser is optional.

Add the repo and install

helm repo add gfs https://hrodrig.github.io/groot-share-selfhosted
helm repo update
helm install gfs gfs/gfs -n gfs --create-namespace -f my-values.yaml
