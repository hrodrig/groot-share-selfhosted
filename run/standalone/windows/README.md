# Windows (standalone)

← [Standalone overview](../README.md).

**Preferred order:** release **`.zip`** from [groot-share Releases](https://github.com/hrodrig/groot-share/releases) → build from source (last).

1. Download `gfs_*_windows_*.zip`, extract `gfs.exe`.
2. Set `GFS_TOPOLOGY`, `GFS_DATA_DIR`, and first-start `GFS_BOOTSTRAP_*`.
3. Run `gfs.exe`.

Production VPS path is Linux + Compose or systemd. Windows is for local lab only.
